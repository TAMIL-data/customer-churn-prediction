Customer Churn Prediction – End-to-End Machine Learning & Streamlit App

An end-to-end machine learning project that predicts customer churn using historical customer data.
The project includes data preprocessing, feature engineering, model training with scikit-learn, and deployment as an interactive Streamlit web application.
Users can input customer details and instantly get churn probability with a business-friendly decision threshold.

Tech Stack: Python, Pandas, NumPy, Scikit-learn, Joblib, Streamlit
Model: Classification model with probability-based churn prediction
Deployment: Streamlit Cloud
